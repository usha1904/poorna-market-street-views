Architectural VR UX & GitHub Workflow Guide

Best practices for Enscape 360, Meta Quest ergonomics, and web hosting

📐 1. VR Human Ergonomics & Spatial UI Guidelines

  • Comfortable Viewing Cone: Keep primary architectural focal points and UI within a 40°–60° vertical/horizontal cone to prevent user neck fatigue.
  • Optimal Panel Distance: Float the spatial dashboard between 1.2m to 1.6m from the user's headset. Closer causes vergence-accommodation conflict (eye strain).
  • Touch Target Sizing: In VR laser pointer or direct hand tracking, targets should be a minimum of 44 × 44 dpmm / pixels with at least 8px margin to avoid mis-clicks.
  • Horizon Plane: Align camera height strictly with human eye level (1.60m – 1.70m) so clients get an accurate perceived scale of ceiling heights.

🌆 2. Exporting Renders from Enscape for WebXR

  1. In Enscape (Revit/SketchUp/Rhino), open Visual Settings > Output.
  2. Set resolution to Panorama: 4096 × 2048 (4K) or 6144 × 3072 (6K). (8K is stunning on desktop, but can stutter on standalone Quest 2/3 headsets).
  3. Click Render Panorama (or Render Stereo Panorama for 3D depth). Save as PNG or high-quality JPG.
  4. You can instantly drag & drop that exported file right into this web tool via the "Load Enscape 360" button!

🚀 3. Free Hosting with GitHub Pages (HTTPS Required for VR)

Meta Quest requires HTTPS for WebXR / WebGL camera motion sensor permissions. GitHub Pages provides this for free out of the box:

1. Create a new GitHub repo: my-vr-architecture

2. Upload this index.html file to the root branch (main).

3. Go to Repository Settings > Pages > Branch: main > Save.

4. Your site is live at: https://yourusername.github.io/my-vr-architecture/

5. Put on your Meta Quest, open the built-in Meta Quest Browser, type your URL, and tap ENTER VR!
